# Zara  — Advanced AI Assistant

Zara is an ongoing personal AI assistant project focused on conversational intelligence, selective personal memory, document-based knowledge retrieval, controlled tool usage, and measurable self-improvement.

## Technology Stack
- Python
- FastAPI
- Ollama
- Qwen3 (reported model)
- PostgreSQL
- psycopg

## Core Systems
- Conversation Intelligence
- Personal Memory System
- System A — Controlled Self-Improvement
- Document Ingestion and RAG
- Semantic Retrieval
- Evaluation and Repair
- Controlled Tool Execution

## Project Status
This project is under active development. Features and evaluation status may change as development continues. Not every planned feature should be considered production-ready.

## Goals
- Evidence-grounded answers
- Context-aware conversations
- Privacy-conscious memory
- Secure and controlled tool execution
- Measurable evaluation and reliability
